# Client

### `void start()`
Запускает клиент в фоновом режиме.

### `void stop()`
Останавливает работу клиента и разрывает активные соединения.

### `void idle()`
Блокирует вызывающий (основной) поток до тех пор, пока клиент находится в рабочем состоянии. Используется, чтобы приложение не завершилось сразу после вызова `start()`.

### `bool connected()`
Проверяет текущий статус соединения.

**Возвращает:**

* `true`, если соединение с сервером активно.
* `false` в противном случае.

### `void on_connect(callback)`
Устанавливает обработчик, который будет вызван сразу после успешной установки соединения.

### `void log(std::string message)`
Выдача логов в формате: `19:55:11.042 | PING= 10ms | message`


## Подсистемы

* **`client->services`** — Remote Services игры.
* **`client->events`** — Remote Listner игры.
