# Fopzo Client
Cпециализированная высокопроизводительная библиотека написанная на **C++**, разработанная для упрощения взаимодействия с игровыми серверами **Standoff 2**. Она выступает в роли посредника, который берет на себя всю работу по сетевому сопряжению, позволяя вам писать приложение для ловли скинов без участия оригинального клиента.

---

## Требования
- `CMake и Ninja`
- `protobuf compiler` и `protobuf-dev`, `openssl lib`, `boost lib`
- `Handshake` (токен для авторизации [подробно](token.md))
